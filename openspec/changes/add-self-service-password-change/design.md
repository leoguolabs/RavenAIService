## Context

工作台设置提供资料和 Agent 偏好。应用登录使用 users 表中的密码哈希和独立签名的会话令牌。

## Goals

让已登录用户在工作台验证当前密码并持久化新密码。

## Decisions

- 在设置中增加「修改密码」分类。表单独立提交，关闭设置或离开分类时清空密码。
- `POST /api/v1/users/auth/change-password` 从会话识别账号。新密码沿用注册的 6 至 256 个字符规则，后端复用 PBKDF2 密码校验和哈希。确认密码仅由界面校验。
- 写入时同时检查账号仍启用且原哈希仍匹配，避免并发提交覆盖彼此。成功响应在提交数据库之后返回。
- 沿用已签发会话的有效期。改密只更新应用登录凭据，管理控制台的独立配置凭据沿用自己的认证流程。

## Risks / Trade-offs

- 密码字段使用敏感类型，请求日志跳过凭据请求体，错误提示仅包含可展示的校验消息。
