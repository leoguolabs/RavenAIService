## Why

Release announcements benefit from a prominent cover image, while maintenance notices should keep the compact text layout users already know.

## What Changes

- Offer classic text and cover image styles in the global announcement editor.
- Let administrators upload one cover, provide alternative text, and preview the full dialog.
- Offer a short, optional fireworks animation for the cover style.

## Capabilities

### New Capabilities

### Modified Capabilities

- `system-announcement` gains selectable layouts, cover uploads, and an optional opening animation.

## Impact

The announcement API, runtime settings record, Admin editor, and workbench dialog gain additive fields and behavior.
